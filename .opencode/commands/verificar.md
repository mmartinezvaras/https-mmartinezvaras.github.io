\---

description: Comprobar el estado real del proyecto

\---

No modifiques ningún archivo. Haz solo esto:

1\. Ejecuta `git status` y muestra la salida completa.

2\. Ejecuta `npx ng build` y muestra la salida completa.

3\. Resume en una línea: ¿compila? ¿qué archivos están modificados o nuevos?

Si el build falla, muestra el error tal cual, sin intentar arreglarlo.
