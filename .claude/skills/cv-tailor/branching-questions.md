# Experience Discovery – Branching Questions

## Overview

When a gap is found between the JD requirements and the user's CV, use these conversational patterns to surface undocumented experience. This is NOT a static questionnaire – each answer informs the next question.

## Technical Skill Gap

```
PROBE: "The job requires {SKILL}. Have you worked with {SKILL} or anything related?"

IF YES (direct experience):
  → "Tell me more – what did you use it for?"
  → "What scale or scope?"
  → "Any measurable results?"
  → CAPTURE: Build detailed bullet

IF INDIRECT (touched it but didn't own it):
  → "What was your role in relation to {SKILL}?"
  → "What did you learn about it?"
  → ASSESS: Enough for a transferable skill mention?
  → CAPTURE: Frame as enabling/support role if substantial

IF ADJACENT (used something similar):
  → "Tell me about your {ADJACENT} experience"
  → ASSESS: Close enough to mention?
  → CAPTURE: Frame as related expertise

IF NO:
  → "Any personal projects, courses, or self-learning?"
  → If yes: explore depth and recency
  → If no: move to next gap
```

## Soft Skill / Leadership Gap

```
PROBE: "The role emphasizes {SKILL}. Tell me about times you've {demonstrated it}."

IF STRONG EXAMPLE:
  → "Who was involved? What was the challenge?"
  → "How did you drive the outcome?"
  → "Measurable result?"
  → CAPTURE: Detailed bullet with impact

IF VAGUE:
  → "Let me rephrase – have you ever {reframed_question}?"
  → "How many people/stakeholders?"
  → CAPTURE: Help articulate clearly

IF FROM SIDE WORK/VOLUNTEER:
  → "Tell me more – what was the scope?"
  → "What skills relate to this job?"
  → ASSESS: Include if it demonstrates the capability
```

## Recent Work Probe

Use this at the end of discovery to catch anything missed:

```
PROBE: "What have you worked on in the last 6 months that isn't in your CV yet?"

IF DESCRIBES SOMETHING:
  → "What was your role? What was the impact?"
  → CHECK: Does this fill any remaining gaps?
  → CAPTURE: Create bullet if relevant

IF "NOTHING NEW":
  → "Any process improvements? New tools? Mentoring?"
  → "Anything that might seem too small to mention?"
  → Small items can fill gaps
```

## Key Principles

1. **Start broad, go narrow** – Open question first, drill into specifics based on answers
2. **Listen and branch** – Promising answer → go deeper. "No" → try adjacent or move on
3. **Know when to stop** – After 2-3 attempts with nothing, move on. Some gaps are OK
4. **Cross-reference** – "Earlier you mentioned X – does that relate here too?"
5. **Don't exhaust the user** – Keep it conversational, not an interrogation
